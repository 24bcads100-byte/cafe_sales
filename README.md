☕ Clean Cafe Sales Prediction

This is a simple Machine Learning mini project for analyzing cleaned cafe sales data and predicting the total sales amount based on customer and transaction details.

📌 Features
Transaction ID
Transaction Date
Item / Product Name
Product Category
Quantity
Price Per Unit
Total Spent / Sales Amount
Payment Method
Location
Transaction Time
🎯 Target / Analysis

The project analyzes:

Total Sales Revenue
Total Transactions
Total Items Sold
Average Transaction Value
Most Sold Products
Most Popular Categories
Sales by Payment Method
Daily / Monthly Sales Trends
Sales by Location
Quantity Sold by Product
Prediction of Total Sales / Total Spent
🔧 Algorithm / Technology

Python Machine Learning & Data Analysis

Libraries used:
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Streamlit
🤖 Machine Learning Algorithm

Random Forest Regression

The model predicts Total Spent using features such as:

Quantity
Price Per Unit
Payment Method
Location
Product Category
